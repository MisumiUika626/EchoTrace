# EchoTrace 实现计划

按项目提示词第 13 节已确认的决定执行，不重复询问 A1–A7。本文记录可演示的阶段与实际边界。

## 目录

```text
echotrace/
  api/        HTTP 路由与本机访问保护
  db/         SQLite WAL、FTS5 与迁移
  ingest/     QCE 客户端、流式解析与清洗
  stats/      离线统计与雷达锚点
  jobs/       持久任务、取消与恢复
  llm/        模板、适配器、结构校验、用量
  distill/    分片、画像、雷达、Skill、版本
  rag/        本地索引与混合检索
  advisor/    求助与模拟对话
prompts/      可编辑的中文提示词
web/          React + TypeScript + ECharts
tests/        虚构夹具与自动化验收
scripts/      夹具生成、构建与性能验证
data/         本地运行数据（不进 Git）
```

## 分阶段交付

1. M0/M1：工程、启动、设置、任务、5,000 条虚构夹具；文件/粘贴导入、角色确认、清洗、体检与消息浏览。验证幂等、边界、性能和离线启动。
2. M3/M4：统一模型调用、明确外发确认、持久分片、四件套、雷达、Skill 质检与安装。用测试模型验证全流程，不把模拟结果声称为真实模型质量。
3. M5/M6/M7：检索、人工语料、三策略求助、模拟对话、版本快照、增量与回滚。验证证据归属及数据一致性。
4. M2/交付：QCE 引导、只读 HTTP 对接、导出自动导入；构建前端、浏览器验收、更新 README 与进度报告。

## 规格冲突处理

- 画像板块采用正文 M4 的八项键，统一使用 evidence（数据库消息 ID）。模型模板也用同一结构，避免附录旧字段冲突。
- 原文发送需要应用内显式确认；开发过程中不调用收费模型、不使用真实聊天记录。
- 首次运行不下载嵌入模型。默认提供明确标识的本地词项哈希向量，可配置已在本地的语义模型；不会将词项向量误称为语义理解。
- 本项目许可证由所有者选择，未擅自指定。
