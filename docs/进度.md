## 验证环境与结果

- Windows 11 10.0.26200，Python 3.14.0，Node.js 24.14.0，npm 11.12.0，Microsoft Edge + Playwright，sqlite-vec 可用。
- 27 项自动化测试通过，耗时 24.98 秒；3 条依赖弃用警告来自 jieba/pkg_resources、Uvicorn/websockets。测试涵盖导入、模型适配/校验/断连、QCE 模拟协议、隐私、引用归属、范围、版本、缓存、恢复、CLI。
- TypeScript 类型检查、Vite 生产构建及静态资源打包通过。
- 浏览器以 5,000 条虚构消息完成导入、身份确认、蒸馏、画像、雷达、语料、Skill、本地重建、Top 3、单条重生、模拟、版本、设置、QCE 引导；共 31 次模拟模型调用，JS 错误 0、HTTP 5xx 0、浏览器外部请求 0。本地 Skill 重建产生 v2，新增模型调用 0。
- 根据使用中的截图修复侧栏：小高度窗口收起装饰，设置入口保留在可见范围。额外验证 1280×600、1024×480、820×400、390×600 的设置导航，以及 390px 下五个主要页面无横向溢出。[设置截图](verification/09-settings-short-window.png)
- 性能测试计时范围为解析、清洗、写库、FTS 与统计，不含文件生成和模型蒸馏；记录为虚构 JSONL。峰值 RSS 是该测试进程的采样值，不是全系统内存。不同硬件、格式和文本长度会改变结果。

复现命令（在项目根目录 PowerShell 执行）：

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
$env:TEMP="$pwd\web\.build-tmp"
$env:TMP=$env:TEMP
New-Item -ItemType Directory -Force $env:TEMP | Out-Null
.\.venv\Scripts\python.exe -m pytest -p pytest_asyncio.plugin -q --junitxml=docs/verification/pytest.xml
.\.venv\Scripts\python.exe scripts/build.py
.\.venv\Scripts\python.exe scripts/verify_browser.py
.\.venv\Scripts\python.exe scripts/verify_recovery.py
.\.venv\Scripts\python.exe scripts/verify_startup.py
.\.venv\Scripts\python.exe scripts/benchmark.py --count 10000
.\.venv\Scripts\python.exe scripts/benchmark.py --count 1000000
```

浏览器脚本需要 `pip install playwright` 与本机 Edge。验证脚本只停止自己创建的服务/子进程，不操作用户已运行的服务。脚本生成的原始测试目录位于被 Git 忽略的 `data/verification/`、`data/recovery/`、`data/startup/`、`data/benchmark/`；可提交的小报告与界面截图单独保存在本目录 `verification/`，不包含数据库或密钥。上传源码前已将约 1.1 GB 的本轮安装缓存、临时目录及虚构测试中间数据移出项目，归档至系统临时目录；保留报告和截图，可运行上述脚本重新生成测试数据。

## 实现取舍与待办

1. 真实模型：在设置页由用户配置 Base URL、API Key、模型 ID 和思考参数适配器；模型列表连通不代表生成与思考参数生效。真实生成质量、20 条结论人工核对尚未完成。
2. 真实 QCE：本机未安装；对接仅通过模拟验证，需要独立安装后验证上游版本、私聊导出与自动导入。未分发 QCE，未实现群聊或消息发送。
3. 检索默认使用词项哈希向量；语义模型需要用户提供已有本机路径，不自动下载。sqlite-vec 不可用时有本地降级。
4. 模拟对话 SSE 在整个结构化输出校验后分段发送，尚非上游原生 token 流。深度档全量分片，其他档确定性抽样；追加后尾片或抽样变化可能重算，不保证理论最少增量。
5. schema 连续校验失败会保存 review 并使任务失败，保护已发布版本；未实现把宽松解析产物标成“待人工复核画像”后发布。
6. 时间轴日期为证据消息日期，不证明事件实际发生日期。八维统计为可调整映射的文本指标，不是心理测评。
7. 媒体仅保留元数据/占位；HTML 整体读取，百万记录优先用 JSONL。中断导入时 health.json 可能仍是上次完成值，恢复后重算。
8. API 按数据库指向的版本快照读取；发布同时更新根目录便利副本，文件系统与 SQLite 不是跨介质原子事务，进程中断时根目录副本可能暂时不一致。
9. 聊天与密钥未加密，Windows chmod 并非完整 ACL 隔离；备份需先停服务并保存整个数据目录。未验收干净机器安装、系统级抓包或自动浏览器打开。
10. EchoTrace 自身许可证待项目所有者决定。依赖弃用警告仍存在，已约束 setuptools 以兼容 jieba。
